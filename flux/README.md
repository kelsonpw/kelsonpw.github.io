# FLUX
An interactive particle sculpture built with Canvas 2D and a custom perspective projection. No build step or JavaScript dependencies. Serve the repository and open `/flux/`.

Four forms: Lorenz attractor (Euler integration), torus, double helix, and a sinusoidal interference surface. Transitions interpolate the same particle positions. Desktop uses 6,500 particles; narrow screens use 3,600. Pointer drag orbits, wheel/pinch zooms, keys 1–4 switch forms, Space pauses. PNG capture exports the canvas locally. Reduced-motion preferences start the visualization paused.

Fonts: DM Sans and Space Grotesk from Google Fonts, with system fallbacks.
